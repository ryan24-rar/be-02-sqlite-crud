# Books to Scrape Web Scraper

A Python web scraper that extracts book information from the **Books to Scrape** website, validates and normalizes the data using **Pydantic**, and exports the results as JSON.

---

# Target Classification

**Target Website**

https://books.toscrape.com

**Classification**

Static HTML website.

**Reason**

All required information is contained directly in the HTML returned by the server. No JavaScript rendering or browser automation is required.

---

# Features

- Crawls multiple catalogue pages
- Discovers product detail pages
- Extracts structured book information
- Normalizes prices, ratings, and stock information
- Validates records using Pydantic
- Retries failed requests once for temporary server errors
- Caches downloaded pages
- Produces JSON output and a run report

# Output

Running the scraper generates the following files inside the `output/` directory:

- `books.json`
- `errors.json`
- `run-report.json`

---

# Record Schema

Each book record contains the following fields:

| Field | Description |
|--------|-------------|
| title | Book title |
| product_url | URL of the product page |
| source_page | Catalogue page where the book was discovered |
| fetched_at | Timestamp when the record was collected |
| category | Book category |
| description | Product description |
| price_text | Original price text |
| availability_text | Original stock text |
| rating_text | Original rating text |
| price_gbp | Normalized numeric price |
| stock_count | Number of books in stock |
| in_stock | Boolean stock status |
| rating | Numeric rating (1–5) |

---

# Politeness Rules

This scraper follows responsible scraping practices.

- Uses a custom User-Agent.
- Uses a 0.5 second delay between requests.
- Uses a 5 second request timeout.
- Retries once for temporary server errors (500, 502, 503, 504) and request timeouts.
- Uses a local cache to reduce unnecessary requests.

---

# Why No Browser Was Needed

This website serves all required data directly in the HTML response. Since the information is already available without JavaScript rendering, browser automation would only increase complexity and resource usage.

# Ethics

When an official API is available, it should be used instead of web scraping. This scraper does not bypass authentication, paywalls, or access restrictions and only collects publicly available information required for educational purposes.
