# Backend Engineering - A4 Authentication

## Overview

This project implements user authentication using FastAPI and Supabase.

## Features

- User signup
- User login
- JWT authentication
- Public endpoint
- Protected endpoint
- Token verification using HTTP Bearer authentication

## Tech Stack

- Python
- FastAPI
- Supabase Auth
- JWT
- Swagger UI

## Run the project

```bash
python -m uvicorn auth_app:app --reload
```

Open:

```
http://127.0.0.1:8000/docs
```

to test the API.
